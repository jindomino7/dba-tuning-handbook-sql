## [현업DBA의 실무사례 튜닝 핸드북] 실습용 SQL 스크립트

전자책 『현업DBA의 실무사례 튜닝 핸드북』 부록의 실습용 SQL 스크립트입니다.
책에 실린 사례를 내 MySQL에서 그대로 재현하고, 튜닝 전/후 `EXPLAIN` 실행계획을 직접 비교해 볼 수 있습니다.

- 모든 테이블명, 컬럼명, 데이터는 학습용으로 만든 가상 값입니다. 실제 서비스 데이터는 포함되어 있지 않습니다.
- 데이터는 스크립트가 직접 생성합니다(대량 데이터 포함). 별도 덤프 파일은 없습니다.
- 사용 조건은 [LICENSE](LICENSE)를 확인해 주세요.

## 준비물

| 항목 | 내용 |
|---|---|
| DBMS | **MySQL 8.0 이상** (재귀 CTE를 사용합니다) |
| 스키마 | `handbook` (스크립트가 `CREATE DATABASE IF NOT EXISTS handbook`으로 만듭니다) |
| 문자셋 | 클라이언트를 utf8mb4로 연결하세요. 테이블명/컬럼명이 한글입니다. |
| 디스크 | 사례에 따라 다르며, 가장 큰 6번 사례는 3~4GB 정도 필요합니다. |
| 메모리 | 버퍼 풀이 기본값(128MB)이면 대량 적재가 매우 느릴 수 있습니다. 아래 "실행 팁"을 참고하세요. |

## 사용 방법

1. 이 저장소를 내려받습니다. (handbook_script.sql 또는 handbook_script.zip)
2. MySQL에 접속합니다.
3. 사례 번호에 맞는 스크립트를 실행합니다.
   MySQL Workbench, DBeaver 등 GUI 도구에서는 파일을 열어 전체를 실행하면 됩니다.
4. 스크립트는 크게 두 부분으로 구성됩니다.
   - 데이터 생성: 테이블 생성, 대량 데이터 입력, 인덱스 생성
   - 실행계획 비교: 튜닝 전 SQL / 튜닝 후 SQL(인덱스 변경 포함)을 `EXPLAIN`으로 확인

5. `EXPLAIN` 결과의 `type`, `key`, `rows`, `Extra` 변화를 책의 설명과 비교해 보세요.

> 스크립트 파일 이름은 `handbook_script.sql` 형식입니다.

## 주의사항

- 운영/개발 서버에서 실행하지 마세요. 연습용 로컬 MySQL이나 별도 테스트 서버에서만 실행하세요.
- 스크립트는 같은 이름의 테이블이 있으면 `DROP TABLE IF EXISTS`로 **삭제하고 다시 만듭니다.** `handbook` 스키마에 다른 데이터를 두지 마세요.
- 대량 데이터를 만들기 때문에 실행에 수 분에서 수십 분이 걸릴 수 있습니다.
- 건수를 줄이고 싶으면 스크립트 상단의 `SET @...cnt := ...;` 변수를 수정하세요. 단, 건수를 줄이면 옵티마이저가 책과 다른 실행계획을 선택할 수 있습니다.
- 일부 스크립트는 실행일(`CURDATE()`)을 기준으로 날짜 데이터를 생성합니다.

## 실행 팁

버퍼 풀이 작아서 느릴 때 (MySQL 기본 설정은 128MB입니다. 서버 메모리가 충분할 때만 늘리세요.)
SET GLOBAL innodb_buffer_pool_size = 2147483648;  -- 2GB

`Recursive query aborted` 오류가 날 때
SET SESSION cte_max_recursion_depth = 1000000;

한글이 깨져 보일 때: 접속 시 `--default-character-set=utf8mb4` 옵션을 사용하거나, GUI 도구의 연결 문자셋을 utf8mb4로 지정하세요.

## 실행계획이 책과 다를 때

실행계획은 MySQL 버전, 설정, 데이터 건수와 분포에 따라 달라질 수 있습니다. 책의 결과와 다르면 다음을 확인해 보세요.

1. 통계 정보를 갱신합니다. `ANALYZE TABLE 테이블명;`
2. 데이터 건수를 확인합니다. `SELECT COUNT(*) FROM 테이블명;`
3. MySQL 버전을 확인합니다. `SELECT VERSION();` (8.0 이상 권장)
4. 옵티마이저는 조건을 만족하는 행의 비율에 따라 인덱스 사용과 FULL TABLE SCAN 중 하나를 고릅니다. 같은 SQL이라도 데이터 분포가 다르면 결과가 달라질 수 있습니다.

> 실제 운영 환경의 튜닝 결과와 실습 환경의 결과는 다를 수 있습니다.
> 이 실습은 수치 자체보다 **튜닝 전후 실행계획의 변화를 비교**하는 데 목적이 있습니다.
